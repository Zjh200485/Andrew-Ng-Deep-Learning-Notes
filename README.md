## 如何记录

1. 点击课程或分集标题，进入对应的 `.md` 笔记；在 GitHub 页面点击编辑按钮即可填写并提交。
2. 每节预留“核心概念、公式与推导、代码与实验、疑问与易错点、参考资料”五部分，可按实际需要删改。
