## 导数是局部变化率

```math
f'(a)=\frac{df}{da}
=\lim_{h\to0}\frac{f(a+h)-f(a)}{h}.
```

图像上是切线斜率；直觉上表示在 $`a`$ 附近，输入微小变化一单位，输出大约变化多少。

```math
\Delta f\approx f'(a)\Delta a,\qquad
f(a+h)\approx f(a)+f'(a)h.
```

导数是变化的比例，不是输出增量本身。

## 直线例子

```math
f(a)=3a,\qquad f'(a)=3.
```

$`a=2`$ 时 $`f=6`$ ， $`a=2.001`$ 时 $`f=6.003`$ ；输入增加 $`0.001`$ ，输出增加 $`0.003`$ ，比值为 $`3`$ 。在 $`a=5`$ 处斜率也为 $`3`$ 。

正导数表示局部同向变化，负导数表示反向变化。导数为零不能单独证明最小值，例如 $`f(a)=a^3`$ 在零点也有零导数。

## 导数与偏导数

单变量函数写 $`df/da`$ ；多变量函数中，固定其他独立变量、只改变其中一个，写偏导数。例如：

```math
J(w,b)=w^2+3b,\quad
\frac{\partial J}{\partial w}=2w,\quad
\frac{\partial J}{\partial b}=3.
```

计算 $`\partial J/\partial w`$ 时把 $`b`$ 当常量。程序中的 dw 是梯度数值，不是“无限小的权重变化”。

~~~python
a, h = 2.0, 1e-6
slope = (3 * (a + h) - 3 * a) / h
assert abs(slope - 3.0) < 1e-8
~~~

有限差分只能近似导数， $`h`$ 过小还可能放大浮点舍入误差。
