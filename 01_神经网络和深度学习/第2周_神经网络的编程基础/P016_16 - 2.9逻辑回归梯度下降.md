## 1. 前向计算

先看单个样本 $`(x,y)`$ 。 $`x,w\in\mathbb R^{n_x\times1}`$ ， $`b`$ 为标量：

```math
z=w^Tx+b,\qquad a=\sigma(z)=\frac1{1+e^{-z}},
```

```math
L(a,y)=-y\ln a-(1-y)\ln(1-a).
```

两特征时 $`z=w_1x_1+w_2x_2+b`$ 。路径为：

```math
(w,x,b)\to z\to a\to L.
```

## 2. 反向求导：为什么是 $`a-y`$

先求损失对预测概率的导数：

```math
da\equiv\frac{\partial L}{\partial a}
=-\frac ya+\frac{1-y}{1-a}.
```

第二项的正号来自 $`\ln(1-a)`$ 的内层导数 $`-1`$ 。又因为：

```math
\frac{\partial a}{\partial z}=a(1-a),
```

链式法则给出：

```math
\begin{aligned}
dz\equiv\frac{\partial L}{\partial z}
&=\frac{\partial L}{\partial a}\frac{\partial a}{\partial z}\\
&=\left(-\frac ya+\frac{1-y}{1-a}\right)a(1-a)\\
&=-y(1-a)+(1-y)a\\
&=-y+ya+a-ya\\
&=a-y.
\end{aligned}
```

$`dz=a-y`$ 来自 **Sigmoid 与二元交叉熵的组合**，不是 Sigmoid 单独的导数。如果换成平方损失 $`\frac12(a-y)^2`$ ，则 $`dz=(a-y)a(1-a)`$ 。

## 3. 参数的梯度

输入和标签在参数求导时视为常量：

```math
\frac{\partial z}{\partial w_j}=x_j,\qquad
\frac{\partial z}{\partial b}=1.
```

所以：

```math
dw_j\equiv\frac{\partial L}{\partial w_j}=x_j(a-y),
\qquad
db\equiv\frac{\partial L}{\partial b}=a-y,
```

```math
dw=x(a-y)\in\mathbb R^{n_x\times1}.
```

两特征时： $`dw_1=x_1dz,\ dw_2=x_2dz,\ db=dz`$ 。
若需要输入梯度，则 $`\nabla_xL=w(a-y)`$ ；训练本模型通常更新 $`w,b`$ ，而不是固定输入 $`x`$ 。

## 4. 更新一次

```math
w_{\mathrm{new}}=w-\alpha\,dw,\qquad
b_{\mathrm{new}}=b-\alpha\,db,\qquad\alpha>0.
```

全部梯度必须在更新前的同一组参数处计算。

若 $`y=1`$ 而 $`a<1`$ ，则 $`dz<0`$ ；仅看偏置更新， $`b`$ 增大，会把预测推向正类。 $`y=0`$ 时相反。权重变化方向还与 $`x_j`$ 的符号有关。

## 5. 一个可以手算的例子

```math
x=\begin{bmatrix}1\\2\end{bmatrix},\quad
w=\begin{bmatrix}0.2\\-0.1\end{bmatrix},\quad
b=0,\quad y=1,\quad\alpha=0.1.
```

前向： $`z=0`$ ， $`a=0.5`$ ， $`L=\ln2\approx0.693147`$ 。

反向： $`da=-2`$ ， $`\partial a/\partial z=0.25`$ ， $`dz=-0.5`$ ，
$`dw=(-0.5,-1)^T`$ ， $`db=-0.5`$ 。

更新结果：

```math
w_{\mathrm{new}}=\begin{bmatrix}0.25\\0\end{bmatrix},
\qquad b_{\mathrm{new}}=0.05.
```

对同一个样本， $`z_{\mathrm{new}}=0.30`$ ，
$`a_{\mathrm{new}}\approx0.574443`$ ，
$`L_{\mathrm{new}}\approx0.554355`$ 。本例这一步损失下降，不表示任意学习率下都保证下降。

## 6. NumPy 验证

~~~python
import numpy as np

x = np.array([[1.0], [2.0]])
w = np.array([[0.2], [-0.1]])
b, y, alpha = 0.0, 1.0, 0.1

def sigmoid(z):
    # 等价分段形式，避免大负数引起 exp(-z) 溢出
    if z >= 0:
        return 1.0 / (1.0 + np.exp(-z))
    e = np.exp(z)
    return e / (1.0 + e)

def loss(w, b):
    z = (w.T @ x).item() + b
    return float(np.logaddexp(0.0, z) - y * z)

z = (w.T @ x).item() + b
a = sigmoid(z)
dz = a - y
dw, db = x * dz, dz

# 中心差分独立核对解析梯度
h = 1e-6
for j in range(w.shape[0]):
    offset = np.zeros_like(w)
    offset[j, 0] = h
    numerical = (loss(w + offset, b) - loss(w - offset, b)) / (2 * h)
    assert np.isclose(numerical, dw[j, 0], atol=1e-8)
numerical_b = (loss(w, b + h) - loss(w, b - h)) / (2 * h)
assert np.isclose(numerical_b, db, atol=1e-8)

old_loss = loss(w, b)
w_new, b_new = w - alpha * dw, b - alpha * db
print("更新前损失:", old_loss)
print("更新后损失:", loss(w_new, b_new))
assert np.allclose(w_new, [[0.25], [0.0]])
assert np.isclose(b_new, 0.05)
assert loss(w_new, b_new) < old_loss
~~~

输出约为 $`0.693147`$ 和 $`0.554355`$ 。中心差分用于本例验证；训练时使用解析梯度。

## 7. 单样本与训练集的区别

本节推导的目标是单样本 $`L`$ 。对 $`m`$ 个样本：

```math
J=\frac1m\sum_{i=1}^m L^{(i)},\qquad
\nabla_wJ=\frac1m\sum_{i=1}^m x^{(i)}(a^{(i)}-y^{(i)}),
```

```math
\frac{\partial J}{\partial b}
=\frac1m\sum_{i=1}^m(a^{(i)}-y^{(i)}).
```

平均梯度衔接下一节；单样本 $`L`$ 的梯度不额外带 $`1/m`$ 。PDF 正文第43页在单样本段落中提前列出了训练集平均梯度，应区分这两种目标。

**复习检查**： $`a`$ 与 $`\alpha`$ 不混用， $`dw`$ 与 $`w`$ 同形状， $`db`$ 是标量；反向传播算梯度，梯度下降执行更新。
