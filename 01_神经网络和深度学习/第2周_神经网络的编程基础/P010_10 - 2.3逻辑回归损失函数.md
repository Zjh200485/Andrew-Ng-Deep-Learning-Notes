## 单样本损失：二元交叉熵

```math
L(a,y)=-y\ln a-(1-y)\ln(1-a),\qquad a=\sigma(w^Tx+b).
```

$`\ln`$ 是自然对数。分情况看：

```math
L(a,1)=-\ln a,\qquad L(a,0)=-\ln(1-a).
```

答对且越有把握，损失越小；答错却非常自信，惩罚很大。例如 $`y=1`$ ， $`a=0.9`$ 时损失约 $`0.10536`$ ， $`a=0.1`$ 时约 $`2.30259`$ 。

## 全训练集代价

```math
\begin{aligned}
J(w,b)&=\frac1m\sum_{i=1}^m L(a^{(i)},y^{(i)})\\
&=-\frac1m\sum_{i=1}^m
[y^{(i)}\ln a^{(i)}
+(1-y^{(i)})\ln(1-a^{(i)})].
\end{aligned}
```

训练求 $`\min_{w,b}J(w,b)`$ 。 $`L`$ 对应一个样本， $`J`$ 是训练集平均，所有样本共享参数。测试集用于评估，不用于这一步拟合。

## 为什么使用它

伯努利标签的模型概率为：

```math
p(y\mid x;w,b)=a^y(1-a)^{1-y}.
```

取负对数得到 $`L`$ ；在样本独立的建模假设下，最大化全训练集似然等价于最小化平均负对数 $`J`$ 。

平方损失 $`\frac12(a-y)^2`$ 对 $`a`$ 是凸的，但代入 Sigmoid 后，对 $`w,b`$ 一般不凸。固定输入的普通逻辑回归配交叉熵，对 $`w,b`$ 是凸的；不能推广到任意多层网络。凸不保证参数唯一，线性可分数据的无正则逻辑回归甚至可能没有有限参数的最小值。

## 稳定计算（实现补充）

等价的 logit 形式：

```math
L=\ln(1+e^z)-yz
=\max(z,0)-yz+\ln(1+e^{-|z|}).
```

~~~python
import numpy as np

z, y = 0.0, 1.0
loss = np.logaddexp(0.0, z) - y * z
assert np.isclose(loss, np.log(2.0))
~~~

这样可避免直接计算 $`\ln(0)`$ 或大指数。理论中 $`a\in(0,1)`$ ，浮点结果却可能舍入到端点。
