## 怎样使用课程资源

- 视频建立直觉和学习顺序。
- 中文 PDF 用于查找章节与完整推导。
- GitHub 笔记用于比较解释和实现；截图公式应重写并自己核对。
- 讨论区适合提出具体问题，附错误现象、变量形状和最小例子。

建议先看视频，再用自己的话复述，查阅不懂的步骤，最后手算或运行一个例子。

## 本仓库的统一符号

| 符号 | 含义 |
| --- | --- |
| $`x,y`$ | 输入与真实标签 |
| $`a=\hat y`$ | 正类概率的预测 |
| $`w,b`$ | 权重和偏置 |
| $`\alpha`$ | 学习率，与 $`a`$ 分开 |
| $`L`$ | 单样本损失 |
| $`J`$ | 训练集平均损失 |

本地 PDF 为 V5.6，**文件页码 = 正文页码 + 12**，本次参考位置同时标明两种页码。

旧版资料的平台入口、软件说明可能变化，公式也可能有笔误，需按定义和计算图判断。不能只因为“资料这样写”就照搬。

本节没有新的数学推导。
